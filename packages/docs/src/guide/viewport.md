# 视区 <Badge text="1.7.0+" />

> <DVersionSupport version="1.7.0" />

## 概念

从 <DVersion version="1.7.0" /> 开始，我们引入了 `Viewport - 视区` 概念，用于定义弹出层（包括遮罩层）的渲染区域。

默认情况下，所有弹出层将以浏览器窗口为视区（和之前版本 **保持一致** ）。

当使用某个元素作为视区时，弹出层的定位、溢出判断等，都将基于该元素进行计算。

这一概念使得自由控制弹出层的渲染区域成为可能，极大地提高了弹出层定位的灵活性。

## 自定义视区

通过给 `viewport` 选项传入一个元素或元素选择器，我们可以自定义弹出层的渲染区域。

```ts
popup.render({
	component: () => import('./HelloPopup.vue'),
	// 自定义视区
	viewport: '.custom-viewport', // [!code highlight]
})
```

需要注意的是，视区将会全面影响弹出层的所有展示和行为，例如 **遮罩层** 也只会在视区范围内显示，同时 **视图位置** 的判断，**视图位置偏移** 溢出的计算等，都将基于视区进行。
